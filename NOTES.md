# Design decision — map look & marker icons

**Question:** what should the map/marker visual design look like? (previous design felt
"outdated"; plain circle markers)

Explored 3 variants (A — Minimal Pins / light Positron map, B — Night Dashboard / dark map
+ badge markers, C — Playful Bubbles / colorful Voyager map + 🅿️ bubbles).

**Verdict:** combined pieces from two variants — variant A's teardrop pin markers
("P" mark, colored by status) + variant C's colorful CARTO Voyager basemap. Folded
directly into `index.html`; the other variants and the prototype switcher bar were
deleted.
